# El Tumi Café — site

Site do El Tumi Café (café peruano no Bigorrilho, Curitiba). Arquivo principal: `index.html`.

- `fotos/` — fotos da casa (do proprietário)
- `logo.png`, `favicon.png`, `icon-180.png` — logo

## Editar
No `<script>` do `index.html`:
- `CONFIG` — Instagram, endereço do mapa, horários, contador de curtidas
- `MENU` — cardápio completo (preço, descrição, tags `fav` / `veg` / `gf`)
- `PHOTOS` — fotos da seção Destaques
- `PRAISE` — avaliações e imprensa

Publicado com GitHub Pages: https://moshikgueta.github.io/El-tumi/
